# Episode machine

Every topology is a trilogy. Next topology is the mitigation.

| Ep | Name | Job | Repo must contain |
| --- | --- | --- | --- |
| A | Budget | SKU, cash vs replace, cap, what you will not buy. Packet Tracer in the 1A gap. | BOM + do-not-buy |
| B | Harden | From zero. Firewall / OS / VLANs / healthy screenshot. | Screenshot in assets |
| C | Weather + IR | Named attack on *this* fabric. Signature. Ticket. | ticket.md + detections.md + aar.md |

Runtime ≤ 8 minutes. 4 + 4. If it needs a fifth minute, it is a cookbook page.

On-camera spine for C:

1. Office and budget (90 seconds)
2. What this box is for (90 seconds)
3. Attack on *this* path
4. What logged / what was blind
5. Change order: one control next week

C is signatures and the IR close. Weather is fiction.

Every C episode needs a host or identity IoC, not only a packet.
