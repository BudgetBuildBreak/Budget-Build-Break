# Budget. Build. Break.

**Budget the build. Secure the network. Then we break it.**

SoHo lab. Cheap gear with a job. A real fabric. Then we break *this* build so the threat looks like it does on your network — not on a slide.

YouTube: [Budget. Build. Break.](https://www.youtube.com/channel/UC1IUhkhpBqSj5mL0t13OZow)

This repo is the paper behind the camera: series map, BOMs, threat one-pagers, and the templates that keep later episodes honest.

---

## Thesis

| Beat | Rule |
| --- | --- |
| **Budget** | Cheapest box that still has one sentence of purpose. Power and noise count. |
| **Build** | Every hop mapped. Why it exists. Where it sits. What trusts it. |
| **Break** | Attack *this* topology. Show the signature — log, packet, light — not the tool name. |

We do not review gear. We budget it, we build it, we break it.
